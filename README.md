I'm Lead AI Engineer at a legal-AI startup in the US (remote), based in Dhaka, Bangladesh. I build agent orchestration, real-world tool integration and the evaluation that shows whether an agent works. I'm also an MSc researcher at RUET on agent security and LLM alignment. Before this I led the Core RAG & AI team at [AskTuring.ai](https://askturing.ai), where usage grew from 100 to 10,000+ users and hallucinations fell by 98%.

My agent Quicksilver won Pokémon VGC Doubles at the UCLA AltruAgent tournament (2026), and I won the Google Nano Banana Hackathon (2025).
